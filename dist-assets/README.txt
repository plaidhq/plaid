Plaid 语音输入 —— 安装与授权

按住右侧 Option（⌥）说话，松开后文字直接粘贴到当前输入框。
轻点一下右 ⌥ 进入连续听写（浮窗显示「⏎ 结束 · esc 取消」）：再按 ⌥ 或 ⏎ 结束，esc 取消。按住说话时 ⏎、esc 同样有效，松手后录音没停（例如遥控器没发出松开）也能用它们收尾。
按键可以在 设置 → 设置 → 快捷键 里改：「按住说话」是长按说话的键，「轻点开关」是短按进入连续听写的键，
两者可以设成同一个键，也可以分开设，或者点「关闭」关掉其中一个。支持单个修饰键（左右 ⌘ ⌥ ⌃ ⇧、fn）或普通键（如 F13）。

一、安装
把 Plaid 拖进「应用程序」(Applications) 文件夹。

二、首次打开（这个 App 没有经过 Apple 公证，需要手动放行一次）
1. 在「应用程序」里双击 Plaid，会提示"无法验证开发者"或"Apple 无法检查其是否包含恶意软件"，点「完成」/「取消」。
2. 打开「系统设置 → 隐私与安全性」，滚到最下面，看到"已阻止使用 Plaid"，点「仍要打开」，输入开机密码确认。
3. 再次双击 Plaid，弹窗中选「打开」。
如果第 2 步找不到按钮，也可以在「终端」里执行这一行，然后直接双击打开：
    xattr -dr com.apple.quarantine /Applications/Plaid.app

三、授权（两个都要）
1. 麦克风：首次打开时弹窗，点「允许」。
2. 辅助功能（用于监听右 ⌥ 和粘贴文字）：
   「系统设置 → 隐私与安全性 → 辅助功能」，打开 Plaid 的开关。
   列表里没有 Plaid 就点「+」，从「应用程序」里选 Plaid 添加。
授权后如果按右 ⌥ 没反应，退出 Plaid（菜单栏麦克风图标 → 退出）再重新打开。

四、填写 API Key
Plaid 使用火山引擎的语音识别服务，需要你自己的 Key：
1. 登录火山引擎控制台（volcengine.com），进入「豆包语音」，开通「流式语音识别大模型」（小时版）。
2. 在控制台创建 API Key。
3. 首次打开 Plaid 会弹出设置窗口，在「设置」页填入 API Key。
之后可以从菜单栏的麦克风图标 → 设置… 再打开设置。

五、可选：LLM 优化
设置 → 优化 页可以接入一个大模型，把识别结果去掉口头禅、修正错字、整理标点后再粘贴。
点「预设」（例如 Volcengine Ark），填模型名和该服务的 API Key，打开开关，在「测试」里点「运行」试一下。
用豆包 Seed 模型时建议在「额外请求体」填 {"thinking":{"type":"disabled"}}，速度更快。

六、麦克风
Plaid 默认用系统当前的输入设备。如果系统输入被别的软件改成了虚拟声卡（例如遥控器麦克风的 MiRemoteV 2ch、BlackHole），Plaid 会提示「几乎没有声音」或「音量过低」，这时漏字、整句为空都是声音没录进来。在 设置 → 设置 → 麦克风 →「输入设备」里单独给 Plaid 选内置麦克风或耳机即可，不影响其他 App。
如果松开按键后最后一个字经常丢：同一页展开「高级设置」，「松键收尾 → 静音阈值」下面会显示上一句的噪声和语音音量，把阈值拖到两者之间、靠近噪声的位置（越小越不容易丢字，但出字会稍慢）；也可以把「最长收尾」调大。

七、越用越准
- 「设置 → 高级设置 → 云端识别」的「二遍识别」默认开启：松键后再整句识别一次，难词更准，出字约慢 300 ms；中英混说较多时如果觉得变差，可以关掉对比。
- 识别错的专有名词、人名，可以写进 设置 → 词典 的热词（一行一个）。
- 你手动改过的粘贴结果，Plaid 会记下来，在 设置 → 词典 页列出建议，点「加热词」/「加别名」采纳，不会自动生效。
- 自动学习（设置 → 词典，默认开启）：某个词被 LLM 优化或你的手动修改改成热词里的写法 2 次以上，Plaid 会自动加一条替换规则，HUD 提示「学会：…」，可在词典页点「忽略」撤掉。没开优化时，Plaid 会在粘贴后于后台把含中文的识别文本交给已配置的模型（或钥匙串里已有 Key 的 DeepSeek）校对一次，只用于学习，不改变粘贴结果；没有可用模型时什么也不做。
- 最近 500 条录音保存在本机（~/Library/Application Support/Plaid/audio），「历史」页可以回放。
- 识别不准时，在「历史」页选中那几条（⌘ 点击多选；不选则是最近 20 条），点「导出…」存成一个 zip 发给我。里面有识别文本、对应录音、当时发给识别服务的上下文（光标前的文字等）、热词和设置，不含 API Key。

八、语音命令（可选）
设置 → 命令 页可以把一句话变成一条 shell 命令（也能调用 osascript、node 等脚本），例如「Plaid，搜索 Swift 并发」打开浏览器搜索。
1. 点「添加」选一个示例（搜索、今天日期、暂停音乐、通知），或者新建空白命令：填命令名（可加别名）和要执行的命令。
2. 触发方式：默认要先说唤醒词「Plaid」再说命令名；也可以改成「直接说命令名」，但口述内容碰巧以命令名开头时也会执行。
3. 命令名后面说的内容放在环境变量 $PLAID_ARGS 里（引用时加双引号 "$PLAID_ARGS"），整句在 $PLAID_TEXT。
4. 输出可以选：不处理、在浮窗显示最后一行、粘贴到光标处。打开「执行前确认」后，识别完要按 ⏎ 才执行，esc 取消。
5. 每条命令下面的「试运行」可以先试一下。没有添加任何命令时一切照常听写。
用 AppleScript 控制其他 App（如「暂停音乐」）第一次执行时，系统会询问是否允许 Plaid 控制该 App，点「好」。

九、常见问题
- 用 fn 当热键时可能同时触发系统的 🌐 功能，可在「系统设置 → 键盘」里把「按下 🌐 键时」设为「不执行任何操作」。
- 按右 ⌥ 没反应：检查辅助功能开关；更新 Plaid 后可能需要在辅助功能里把 Plaid 删掉重新添加。
- 文字没粘贴进去：同上，粘贴也依赖辅助功能权限。
- 识别报错：检查 API Key，以及火山引擎控制台里服务是否已开通、是否有余额。
- 系统要求：macOS 14 或更高，仅支持 Apple 芯片（M 系列）。

数据说明：语音发送到火山引擎识别；为提高准确率，当前输入框里光标前的一小段文字（最多约 300 字）、最近几次的识别结果和当前应用名也会一起发给火山引擎，可在「设置」页关闭「发送上下文」；
录音和修改记录只保存在本机，可在「设置」页关闭；开启 LLM 优化后，识别文本、当前应用名和窗口标题会发送给你配置的模型服务。自动学习开启且有可用模型时，即使没开优化，识别文本也会发送给该模型服务（可在「词典」页关闭）。Key 存在本机钥匙串里。
